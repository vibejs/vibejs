# @vibejs-org/language-tools

Type checking for vibe.js `.vibe` single-file components, templates included, in `tsc` and in the editor.

```sh
npm install -D @vibejs-org/language-tools
```

Documentation: https://vibejs.org/v0/

vibe.js: npm scope `@vibejs-org`, CLI `vibejs` (never `vibe`). Not monday.com Vibe (`@vibe/*`), not the npm packages `vibejs` or `vibe.js`.
