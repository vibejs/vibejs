# @vibejs-org/cli

The `vibejs` command line: dev server, build, checks, generators, JSON output and an MCP server for coding agents.

```sh
npm install -D @vibejs-org/cli
```

Documentation: https://vibejs.org/v0/

vibe.js: npm scope `@vibejs-org`, CLI `vibejs` (never `vibe`). Not monday.com Vibe (`@vibe/*`), not the npm packages `vibejs` or `vibe.js`.
