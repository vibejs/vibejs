# vibe.js

vibe.js: npm scope `@usevibejs`, CLI `vibejs` (never `vibe`). Not monday.com Vibe (`@vibe/*`), not the `@vibe.js/*` packages (a different project), not the npm packages `vibejs` or `vibe.js`.

A full-stack TypeScript framework where the UI, the server and the contract between them are type-checked end to end, and every tool speaks to coding agents as well as to people.

- [Getting started](/guides/getting-started): create an app, run it and check it.
- [Tutorial](/guides/tutorial): add an API resource and a page, catch a type error, then build and serve the app.
- [CLI reference](/cli/): every `vibejs` command, its options and examples.
- [Error codes](/errors/): every `VIBE####` code with its message and fixes.
