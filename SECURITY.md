# Security policy

## Reporting a vulnerability

Do not open a public issue, discussion or pull request for a security problem. Report it privately through GitHub private vulnerability reporting: on the repository page, open **Security**, then **Report a vulnerability**.

Include the affected package and version, the steps to reproduce, and the impact you expect. The maintainers will acknowledge the report, investigate it, and agree on a disclosure date with you before a fix is published. Reporters are credited in the advisory unless they ask not to be.

## Supported versions

vibe.js is pre-release and no version has been published yet.

| Version            | Supported |
| ------------------ | --------- |
| `main` branch      | Yes       |
| Published releases | None yet  |

Once v0.1.0 is published, the latest minor release receives security fixes; this table will list the supported versions from then on.
