# @usevibejs/compiler

The compiler and Vite plugin that turn vibe.js `.vibe` single-file components into fine-grained DOM code.

```sh
npm install -D @usevibejs/compiler
```

Documentation: https://vibejs.org/v0/

vibe.js: npm scope `@usevibejs`, CLI `vibejs` (never `vibe`). Not monday.com Vibe (`@vibe/*`), not the `@vibe.js/*` packages (a different project), not the npm packages `vibejs` or `vibe.js`.
