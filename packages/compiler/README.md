# @vibejs-org/compiler

The compiler and Vite plugin that turn vibe.js `.vibe` single-file components into fine-grained DOM code.

```sh
npm install -D @vibejs-org/compiler
```

Documentation: https://vibejs.org/v0/

vibe.js: npm scope `@vibejs-org`, CLI `vibejs` (never `vibe`). Not monday.com Vibe (`@vibe/*`), not the npm packages `vibejs` or `vibe.js`.
