# vibe.js

vibe.js: npm scope `@vibejs-org`, CLI `vibejs` (never `vibe`). Not monday.com Vibe (`@vibe/*`), not the npm packages `vibejs` or `vibe.js`.

A full-stack TypeScript framework where the UI, the server and the contract between them are type-checked end to end, and every tool speaks to coding agents as well as to people.

- [CLI reference](/cli/): every `vibejs` command, its options and examples.
- [Error codes](/errors/): every `VIBE####` code with its message and fixes.
